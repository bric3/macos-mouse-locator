# Mouse Locator

A native macOS menu bar app that makes the pointer easier to find.

## Requirements

- macOS 14 or later
- Swift 6 toolchain

## Build

```sh
make test
make app
open .build/MouseLocator.app
```

Mouse Locator is available from the menu bar. Its two effects can be enabled
together and configured from Settings.
